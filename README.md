# MonkFlow

Трекер тренировок. Работает в браузере и с экрана «Домой», данные хранятся на устройстве.

## Как устроено
- `src/app.html` — исходник приложения (тот же, что и версия в Claude).
- `src/local.js` — хранение данных на устройстве (IndexedDB), резервная копия.
- `src/sw.js` — офлайн-кэш.
- `src/seed.json` — общая библиотека упражнений и комплексов (без личных данных).
- `python3 tools/build.py` собирает `index.html`, `sw.js`, иконки и манифест в корень, откуда их отдаёт GitHub Pages.
